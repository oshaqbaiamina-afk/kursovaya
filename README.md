## Жоба туралы

**Oylar** — сауалнама жасауға, жариялауға және нәтижелерін бақылауға арналған толыққанды веб-платформа. Пайдаланушылар тіркелуі, жеке кабинетінде сауалнама құруы, оларды жариялауы және қатысушылардың жауаптарын статистика түрінде көруі мүмкін.

**ПМ04 — Web-сайтты жобалау және үздіксіз жұмыс істеуін қамтамасыз ету** пәні бойынша курстық жоба.

## Функционалдылық

- Пайдаланушыны тіркеу және жүйеге кіру (JWT)
- Профильді өзгерту (аты-жөні, аватар)
- Сауалнама жасау (бір таңдау, көп таңдау, мәтіндік жауап)
- Сауалнаманы жариялау / жобаға сақтау
- Жарияланған сауалнамаларды шолу және жауап беру
- Нәтижелерді статистика түрінде көру (диаграммалар)
- Пікір қалдыру
- Жалпы статистика (пайдаланушылар, жауаптар, сауалнамалар)

## Орнату

### Талаптар

- Node.js 18+
- PostgreSQL 14+

### Қадамдар

**1. Репозиторийді клондау**

```bash
git clone https://github.com/<your-username>/oylar.git
cd oylar
```

**2. Тәуелділіктерді орнату**

```bash
npm install
```

**3. `.env` файлын жасау**

Түбірлік папкада `.env` файлын жасап, мына мәндерді толтырыңыз:

```env
DB_NAME=oylar
DB_USER=postgres
DB_PASS=your_password
DB_HOST=localhost
DB_PORT=5432
PORT=3000
JWT_SECRET=your_secret_key
```

**4. PostgreSQL-да дерекқор жасау**

```sql
CREATE DATABASE oylar;
```

**5. Серверді іске қосу**

```bash
npm start
```

Сервер іске қосылғаннан кейін Sequelize кестелерді автоматты түрде жасайды (`sync({ alter: true })`).

Браузерде ашу: [http://localhost:3000](http://localhost:3000)

## API эндпоинттері

### Аутентификация `/api/auth`

| Метод | Эндпоинт | Сипаттама | Auth |
|---|---|---|---|
| POST | `/register` | Жаңа пайдаланушы тіркеу | — |
| POST | `/login` | Жүйеге кіру, JWT алу | — |
| GET | `/me` | Ағымдағы пайдаланушы мәліметі | ✅ |
| PATCH | `/profile` | Профильді жаңарту (аватармен) | ✅ |

### Сауалнамалар `/api/surveys`

| Метод | Эндпоинт | Сипаттама | Auth |
|---|---|---|---|
| GET | `/` | Жарияланған сауалнамалар тізімі | — |
| GET | `/my` | Менің сауалнамаларым | ✅ |
| GET | `/stats` | Жалпы статистика | — |
| GET | `/activity` | Соңғы белсенділік | — |
| GET | `/:id` | Жеке сауалнама | — |
| POST | `/` | Сауалнама жасау | ✅ |
| PUT | `/:id` | Сауалнаманы өзгерту | ✅ |
| DELETE | `/:id` | Сауалнаманы жою | ✅ |
| POST | `/:id/respond` | Жауап жіберу | — |
| GET | `/:id/results` | Нәтижелер (тек автор) | ✅ |
| GET | `/:id/results/public` | Жалпы нәтижелер | — |
| GET | `/:id/comments` | Пікірлер тізімі | — |
| POST | `/:id/comments` | Пікір қалдыру | ✅ |

> ✅ — `Authorization: Bearer <token>` тақырыбы қажет
